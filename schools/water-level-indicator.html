💧 Water Level Indicator

Warns you with a buzzer when a water tank is almost full or almost empty.

⭐ Beginner Suitable for: School Students / Science Exhibition

Overview

This project monitors the water level inside a tank and sounds a buzzer plus lights an LED when the level crosses a low or high mark — helping avoid overflow or running dry.

How It Works

A sensor strip placed inside the tank gives different readings depending on how much of it is submerged in water. The Arduino checks these readings continuously.

Components Required

Water level sensor strip, Buzzer, LEDs, Arduino Uno

Working Principle

Water conducts electricity slightly, so submerged sensor strips change the circuit's resistance, which the Arduino reads as a changing analog value.

What You'll Learn

Analog sensing and how to set safe threshold values for alerts.

Project Features

  • Prevents tank overflow
  • Simple visual + audio alerts
  • Can be adapted for any size tank

Optional Upgrades

  • Add a motor pump that switches off automatically when full
  • Send an SMS/notification alert
  • Display exact percentage on an LCD
