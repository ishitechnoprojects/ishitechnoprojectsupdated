🌧️ Rain Alarm

Detects raindrops and sounds an alert so you know it's started raining.

⭐ Beginner Suitable for: School Students / Science Exhibition

Overview

This device sits outside and alerts you the moment it starts raining — handy for knowing when to bring in laundry or close windows.

How It Works

The rain sensor's surface changes its electrical resistance when water droplets land on it. The Arduino monitors this value and sounds the buzzer once rain is detected.

Components Required

Rain sensor module, Buzzer, Arduino Uno

Working Principle

Water bridges tiny conductive tracks on the sensor board, lowering its resistance as more rain accumulates.

What You'll Learn

Analog thresholds — deciding at what sensor value an action should trigger.

Project Features

  • Instant rain detection
  • Weatherproof-friendly design options
  • Cheap and simple to build

Optional Upgrades

  • Add automatic window/clothesline closing mechanism
  • Log rainfall data over time
  • Add a phone notification
