🏠 Smart Home Model

A tabletop model home showing lights, fans and doors controlled automatically.

⭐ Intermediate Suitable for: School Students / Science Exhibition

Overview

A miniature model house that demonstrates real home-automation ideas — lights that turn on when it's dark, a fan that runs when it's hot, and more.

How It Works

Different sensors monitor conditions like light and temperature. The Arduino processes all these readings together and controls relays connected to small lights and a fan.

Components Required

Relays, Sensors (light/motion), LED bulbs, mini fan, Arduino Uno

Working Principle

This combines several single-sensor projects (like the street light and temperature monitor) into one coordinated system.

What You'll Learn

How multiple sensors and outputs can be combined into a complete automation system.

Project Features

  • Demonstrates several automation ideas at once
  • Great centrepiece for a science exhibition
  • Expandable with more rooms and sensors

Optional Upgrades

  • Add app/voice control
  • Add a security camera model
  • Add solar power for the whole model
