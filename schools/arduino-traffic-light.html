🚦 Arduino Traffic Light

A working miniature traffic signal that cycles Red → Green → Yellow automatically.

⭐ Beginner Suitable for: School Students / Science Exhibition

Overview

A tabletop model of a traffic signal that runs through the same Red-Green-Yellow sequence you see on real roads, timed precisely by code running on the Arduino.

How It Works

The Arduino turns each LED ON and OFF in a fixed order with fixed delays — Red for a while, then Green, then a short Yellow before switching back to Red.

Components Required

3 LEDs (Red, Yellow, Green), Resistors, Arduino Uno, Breadboard

Working Principle

This is a simple example of a 'finite state machine' — the light is always in exactly one of three states, and timers decide when to move to the next one.

What You'll Learn

Sequencing and timing logic — how real traffic signals coordinate to keep roads safe.

Project Features

  • Adjustable timing for each light
  • Can be expanded to a 4-way junction
  • Great intro to Arduino programming logic

Optional Upgrades

  • Add a pedestrian crossing signal
  • Add a countdown timer display
  • Control multiple junctions together
